# 脱敏范围与配置校验的边界

仓库保留路由结构和公共目标域名，替换代理服务器地址、代理用户名/密码/UUID、obfs 密码、Reality 认证材料、节点 SNI/servername、WebSocket Host/path，以及代理服务器别名映射。IPv4 使用文档地址段，IPv6 使用 2001:db8::/32；这些占位端点不能访问真实住宅节点。

原始截图、浏览器资料、OAuth URL、Cookie、NetLog、HAR、安装包、数据库、订阅附件和原始 builders 未复制进仓库。历史文件索引只含文件名、摘要哈希与状态，不含本机用户名、完整绝对路径或账号。

这里保留的是脱敏结构模板，不是可恢复真实账号的备份；没有附带占位符到账号的反向映射。完整配置仍留在原电脑的 outputs/ 及用户原文件位置。不要把整个本地工作目录上传。

浏览器的 TLS 校验与代理节点的 skip-cert-verify 是不同层。核对发现：LinkCube Windows/安卓来源均继承 51 个机场节点的 skip-cert-verify: true；吹雪云重点模板没有 true。本次资料整理原样记录，不擅自修改连接参数，也不把“浏览器证书校验保持开启”写成全部代理节点都校验开启。后续若处理此项，应单独取得供应商要求和实际证书信息，而非借整理机会全改。

check_repository.py 是针对本仓库结构和已知敏感字段的检查，不是所有秘密格式的通用保证。本次交付另外在本地用 62 份源配置的真实敏感值和代理端点做了不回显的精确比对；检查结果见 metadata/validation-report.json。

Git ignore 只保护未跟踪文件，不能撤回已提交的内容。以后加入资料前仍需检查 diff。原资料包生成时没有创建远程仓库、上传文件或改动线上设置；后续仓库导入记录见 [云端导入记录](cloud-import.md)。
