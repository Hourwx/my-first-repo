# 10-25 浏览器环境复查与规则模式对照

证据来自用户截图、只读配置/网卡/路由/版本核对及已有启动器静态检查。没有另启代理核心、批量 curl、测速或改写 FlClash 运行配置。本文使用“国内出口”“住宅出口”代称用户公网地址，不保存实际用户 IP、完整 IPv6、截图或浏览器资料。

## 按时间区分结果

| 阶段 | 证据 | 能支持的结论 |
| --- | --- | --- |
| 普通 Chrome / TUN 路径 | 某些 HTTP 多出口探针出现中国 IPv6；与本机以太网的一个公网 IPv6 完全相同，IPv6 默认路由经以太网 | 当次确有 IPv6 绕行；IPv4 代理成功不能排除它 |
| 显式 7890 Chrome / 全局模式对照 | 多出口显示同一个美国 IPv4、IPv6 未检出、WebRTC 栏未列出公网地址 | 这些探针在本次浏览器路径未暴露原中国 IPv6；不能宣布系统级 IPv6 已修复 |
| 图形加速开启并正常重启后 | 用户截图 WebGL 从 Microsoft Basic Render Driver 变为 AMD Radeon RX 9060 XT，WebGPU 显示 AMD，RAF 警告消失；本地设置也显示加速开启 | 图形加速实际生效，原软件渲染问题改善 |
| DNS 复测 | 一次解析器数量为 0，后续能检出美国解析器；不同截图数量为 2 或 8 | “DNS 黑洞”不持续存在，恢复原因未单独隔离，不能归功于图形加速 |
| 规则模式对照 | 用户仪表盘高亮规则，探针同时显示国内 IPv4 与住宅 IPv4；IPv6 仍未检出；实时连接同时有 Chrome 的 DIRECT 与住宅出站 | 本轮是 IPv4 分流与覆盖范围问题，与前面的物理 IPv6 绕行不同 |

## 当前分流到底意味着什么

这份配置末尾是 MATCH,DIRECT：没有命中前面规则的请求最终直连。它是显式规则列表加直连兜底，不能概括成“所有海外网站都自动代理”。

静态核对：ip.sb、ipinfo.io、get.geojs.io 已有“出口选择”规则；ping0.cc、ipify.org、bigdatacloud.net、ipapi.is 未找到明确 DOMAIN / DOMAIN-SUFFIX / DOMAIN-KEYWORD 代理条目。对应截图确实出现主检测页/部分探针为国内出口，另外几项为住宅出口。每一条具体探针的命中仍需实际请求域名/IP及日志确认，不能只用静态域名检查替代全部逻辑、IP与规则集匹配。

检测站“抖音”“微信”等是它的探针标签，不必然等于浏览器访问相同业务主域名；不能据标签判断 douyin.com 业务代理规则失效。

如果用户目标是保留国内与媒体直连、指定业务走住宅，本次混合出口是可预期的，不需要为了检测分数把所有站改代理。但这不表示所有登录/隐私目标均已覆盖；未命中的站点可能看见国内直连 IP，应按具体用途补规则。

若新目标变成“Chrome 对所有公网网站只暴露住宅出口”，应明确调整 Chrome 保护范围并接受国内网页/视频也可能走住宅的代价。不能仅补几个检测站使分数变绿，就宣称整个浏览器都获得统一出口保护。

## IPv6 的未完成部分

顶层 ipv6=false、dns.ipv6=false 不等于在 Windows 物理网卡禁用或阻断 IPv6。生成配置虽写有 inet6-address，但当次接口/路由检查没有实际 TUN IPv6 地址及覆盖路由。系统级 TUN IPv6 接管或阻断尚未修改，普通入口/其他应用不能直接继承显式 Chrome 对照结果。

全局模式也只影响进入内核的流量；没有进入 TUN 的 IPv6 请求不能靠普通规则里的 IP-CIDR6 REJECT 补救。

## 其余检测警告

- 中文语言、字体：是用户真实中文 Windows 环境；美国代理不会自动改变这些，不据此删字体或伪造语言。
- UA 156 对比推测内核 149–151：运行 Chrome 的 ProductVersion 为 156.0.8078.48，截图 UA、Sec-CH-UA、HTTP 头也为 156，没有发现 Chrome 的 --user-agent 覆盖参数。该站公开脚本使用语法/CSS/API 特征与服务端模型推测版本，不读取本地安装文件。现有证据优先支持检测推测局限，具体误判探针未知，不修改 UA 或降级来凑分。
- DNS 国家差异：检测的是递归解析器出口，国家不同不足以单独证明泄漏。Google 官方网段表把先前截图一组被标为比利时的递归地址段标记为 lax；地理库也可能不同。在规则模式下，主页面国内出口与美国解析器并存可触发同样警告，应结合实际 DNS 路径判断。
- WebRTC：本次栏位未显示公网地址，不等于所有场景的 WebRTC 都已禁用。
- 时区：由用户自己处理，不在本次改动中；不据此修改系统时区。

## 验证边界

本次只修改本地启动器默认目标及桌面快捷方式；用户手动开启图形加速并重启。FlClash 节点、账号、规则、DNS、hosts 及 TUN 设置未由助手在此次复查中改写。直播伴侣官网/安装包成功、全部海外规则覆盖、系统级 IPv6、防泄漏长期有效性仍未获得充分验证。
